# Construction quality increment 1

This branch extends the existing workspace, without changing the registry or original production deployment. On a verified project with pending deliveries, expand Construction quality tools to prepare an MIR. Record the actual project-approved standard edition, clause/ITP reference, criteria, delivery references, observations and proposed accepted quantity. Download the deterministic JSON and attach it using the existing Record inspector decision form. Match the lot, quantity and decision before signing. The exact bytes can be verified in the public passport. The draft is not an approval; its contents are not checked by the contract and the file must be retained separately. Do not enter sensitive personal information in reference fields. There is no shared document storage or walletless login in this increment.

The standards links are catalogue references, not a compliance engine. Nominal rebar mass assumes 7850 kg/m³ and is independent of actual quantities.

Run `npm test`, `npm run typecheck`, `npm run lint`, `npm run build` and the existing Anvil flows before releasing a preview. The isolated branch must not deploy against a funded registry for write tests. The 50,000-block history cap remains unchanged; the frozen release is a source/evidence fallback, not a guarantee of continued public passport availability.
